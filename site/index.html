The cluster is the exam

Every lesson is a small cluster that is broken or unfinished, plus a goal. You fix it with your own kubectl. Nothing is multiple choice: kdrill verify checks the cluster and says exactly what is still wrong.

What's in the box

One lesson, taken apart. Parts are not sold separately.

  1. 1
    A broken clusterA small k3d cluster, broken or unfinished on purpose. One pod is Pending and nobody has said why.
  2. 2
    A goalWhat done looks like, in one sentence: all 3 replicas Running, on the 2 existing nodes, each pod still requesting 1 CPU.
  3. 3
    Your own kubectlNot included. You already have one, and probably an alias for it.
  4. 4
    kdrill verifyChecks the real cluster and tells you exactly what is still wrong. Exits 0 when you are done.
  5. 5
    Progressive hintskdrill hint gives a little more away each time. kdrill solution has the reference answer.
  6. 6
    A reset buttonkdrill reset puts the lesson back the way it started. Break it as often as you like.

Instructions for use

Quick start

  1. git clone https://github.com/mousavian/kdrill
  2. cd kdrill && make build
  3. bin/kdrill doctorChecks docker, memory, k3d, kubectl.
  4. bin/kdrill cluster upOne k3d cluster called “kdrill”.
  5. bin/kdrill start k8s-scheduling/01Your first broken cluster.

Before you start

  • Docker (Docker Desktop, OrbStack or Colima), k3d, kubectl, Go and helm.
  • Give Docker about 4 GB of memory. The whole lab fits on an 8 GB laptop.
  • No cloud account, no cloud bill, no GPU.
