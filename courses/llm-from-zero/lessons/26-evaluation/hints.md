`perplexity_on_text`: keep `scored_upto` (index of the last target already scored, starting at 0) and the window start `s` (starting at 0, growing by `stride`). Each round: `end = min(s + block, n - 1)`; the window's inputs are `ids[s:end]` and its targets `ids[s + 1:end + 1]`; get log-probs with `F.log_softmax(logits, -1).gather(...)`; the NEW tokens are the last `end - scored_upto` of them; add their negative sum to the total, set `scored_upto = end`. Stop when `scored_upto == n - 1`. The result must equal `n - 1` tokens in total.
---
`continuation_logprob`: feed `seq[:-1]` where `seq = prompt + continuation`; the log-probs at the last `len(continuation)` positions, indexed by the continuation tokens, are what you sum. Check the lengths and `block_size` first. `run_probes`: encode the prompt once, compute the good continuation's log-prob and each bad one's, and pass when `good > max(bad)`.
---
`contamination`: build the list of test n-grams and a `set` of train n-grams (words from `re.findall(r"[a-z0-9']+", text.lower())`), count the test n-grams found in the set, return `(count / total, first_three_hits)`. `write_side_by_side`: `rnd = random.Random(seed)` and for each prompt in order `flip = rnd.random() < 0.5`; show `(b, a)` if flipped else `(a, b)` and record in the key which name is "sample1"; write the key as JSON next to the sheet and never put the model names in the sheet itself.
