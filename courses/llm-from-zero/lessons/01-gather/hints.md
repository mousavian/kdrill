Start with `sha256_of` and `fetch` for the happy path against one url, and run `make py F=gather.py` early to see it work for real. `urllib.request.Request(url, headers={...})` lets you set the User-Agent; `urllib.request.urlopen(req, timeout=...)` raises `urllib.error.HTTPError` (which has `.code`) for HTTP errors and other exceptions for network problems.
---
Structure `fetch` as a loop `for attempt in range(retries)`. Inside: try the request; on `HTTPError` decide by `e.code` (429 or >= 500: remember the error and continue; anything else: raise `FetchError`); on any other exception: remember and continue. After a failed attempt that is not the last, call `sleep(backoff * 2 ** attempt)`. Catch a broad `Exception` for network errors: a body that ends early raises something that is not a `URLError`.
---
Write the bytes to `dest + ".part"`, compare `hashlib.sha256(data).hexdigest()` with the expected value, delete the `.part` file and raise `FetchError` on mismatch, otherwise `os.replace(part, dest)`. In `fetch_all`, remember whether the previous book needed a download and only then call `sleep(delay)` before the next one that needs one. `datetime.datetime.now(datetime.timezone.utc).strftime("%Y-%m-%d")` gives the date.
