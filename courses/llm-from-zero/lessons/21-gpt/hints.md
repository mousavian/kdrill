Build the pieces in `__init__` in this order: `tok_emb`, `pos_emb`, `drop`, `blocks` (a `ModuleList` of `n_layer` `Block`s), `ln_f`, `lm_head = nn.Linear(n_embd, vocab_size, bias=False)`, then tie: `self.lm_head.weight = self.tok_emb.weight`. Initialise last: loop `self.modules()`, `nn.init.normal_(m.weight, 0.0, 0.02)` for `nn.Linear` and `nn.Embedding` (and zero any bias), then a second loop over `self.blocks` re-initialising `blk.attn.proj.weight` and `blk.ffn.fc2.weight` with std `0.02 / math.sqrt(2 * n_layer)`.
---
`forward`: `pos = torch.arange(T)`; `x = self.drop(self.tok_emb(idx) + self.pos_emb(pos))` (the position embedding is `(T, C)` and broadcasts over the batch); run the blocks; `logits = self.lm_head(self.ln_f(x))`; if targets: `F.cross_entropy(logits.reshape(-1, V), targets.reshape(-1))`. Raise `ValueError` when `T > block_size`.
---
`num_params`: `sum(p.numel() for p in self.parameters())` already counts the tied matrix once (PyTorch yields shared parameters a single time). `gpt_param_count`: `V*C + T*C + n_layer * block_param_count(C) + 2*C`. If the initial loss is not near `ln V`, print the standard deviation of your logits: it should be tiny.
