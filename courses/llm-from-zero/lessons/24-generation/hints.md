`top_k_filter`: `kth = torch.topk(logits, k, dim=-1).values[..., -1:]` is the k-th largest value of each row; `logits.masked_fill(logits < kth, float("-inf"))` keeps ties. `top_p_filter`: `sorted_logits, order = torch.sort(logits, dim=-1, descending=True)`; `probs = F.softmax(sorted_logits, -1)`; `before = torch.cumsum(probs, -1) - probs`; drop where `before >= p`; map the mask back to the original positions with `scatter(-1, order, drop_sorted)`.
---
`apply_repetition_penalty`: clone the logits; for each row take `torch.unique(generated[b])`, read `vals = out[b, ids]`, and write back `torch.where(vals > 0, vals / penalty, vals * penalty)`. `sample_next`: apply the penalty, return `argmax(dim=-1, keepdim=True)` when `temperature == 0`, otherwise divide, filter with k then p, `F.softmax`, and `torch.multinomial(probs, 1, generator=generator)`.
---
`generate`: remember `was_training`, `model.eval()`, then loop `max_new_tokens` times: `logits, _ = model(idx[:, -model.block_size:])`, `nxt = sample_next(logits[:, -1, :], ..., generated=idx, generator=generator)`, `idx = torch.cat([idx, nxt], dim=1)`. For `eos_id` keep a boolean `finished` per row updated with `nxt[:, 0] == eos_id` and `break` when all are True. Restore the mode with `model.train(was_training)`; the decorator `@torch.no_grad()` is already there.
