`train`: build `counts = Counter()` of `tuple(chunk.encode("utf-8"))` over `pretokenize(piece)` for every non-special piece from `split_on_specials`. Each round: `pc = count_pairs(counts)`; choose with `max(pc.items(), key=lambda kv: (kv[1], -kv[0][0], -kv[0][1]))` (highest count, then smallest ids); stop if the best count is below 2; rebuild `counts` by applying `merge_pair` to each chunk key (keep the multiplicities).

`_encode_chunk`: `ids = list(chunk_bytes)`; loop: among `zip(ids, ids[1:])` pick the pair with the smallest `self.rank.get(pair, infinity)`; if none is in `self.rank` stop; else `ids = merge_pair(ids, pair, 256 + rank)`. `encode`: iterate `split_on_specials(text, self.special_tokens)`; a special piece becomes `self.special_ids[piece]`, other pieces go through `pretokenize` and the cached chunk encoder. `decode`: join `token_bytes` of all ids, then `.decode("utf-8", errors="replace")`.
