Work function by function, in the order of the file, and test each in `kdrill py` before moving on. For `strip_gutenberg` two regexes do the job: one for the start marker (`re.I | re.S` so the title can span lines and letter case does not matter; `.*?` is the lazy version that stops at the first closing `***`) and one for the end marker. Use `match.end()` for the start and `match.start()` for the end.
---
`drop_contents`: split into lines, find the heading with a regex such as `^\s*(table of )?contents\.?\s*$` (ignore case), then scan forward counting consecutive blank lines (`line.strip() == ""`); the block ends at the first non-blank line that comes after 3 or more blanks. Remove lines `[i:end]`, and repeat from the same position because the next heading may already be there. For `drop_illustrations` a pattern like `\[Illustration(?::[^\]]*)?\]` also matches captions that run over several lines, because `[^\]]` includes newlines.
---
`normalize`: do the steps in the order of the docstring, each as a tiny transformation: `unicodedata.normalize("NFC", t)`; `"".join(CHAR_MAP.get(c, c) for c in t)`; filter on `unicodedata.category(c) != "Cc"` (keep `"\n"`, turn `"\t"` into a space first); `re.sub(r" {2,}", " ", t)`; strip each line; `re.sub(r"\n{3,}", "\n\n", t)`. `unwrap_paragraphs`: split on blank lines (`re.split(r"\n\s*\n", t)`) and join each paragraph with `" ".join(p.split())`.
