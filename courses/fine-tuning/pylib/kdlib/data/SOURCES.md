# Sources of the bundled data

- `holmes_{train,val,test}.txt.gz`: the cleaned Sherlock Holmes text of the llm-from-zero course (A Study in Scarlet and
  The Sign of the Four by Arthur Conan Doyle, Project Gutenberg #244 and #2097, public domain in the USA), split by chapter:
  copied unchanged from `courses/llm-from-zero/pylib/kdlib/data/clean_*.txt.gz`. This is what the base model was trained on.
- `alice_{train,val,test}.txt.gz`: Alice's Adventures in Wonderland by Lewis Carroll (1865), Project Gutenberg #11, public domain in the USA
  (author died 1898). Pinned file: `https://gutenberg.pglaf.org/1/11/11-0.txt` (also `https://mirrors.xmission.com/gutenberg/1/11/11-0.txt`),
  151,191 bytes, sha256 `a3a27f8edbf7fcd9b8ba8435494440e24952deaa3e2f2d65192d4cb7ca403754` (recorded 2026-11-25). Cleaned and split by chapter with
  `hack/make_alice.py`: chapters I-VIII train (97,264 characters), IX-X validation (24,010), XI-XII test (21,947).
- `qa_*.jsonl`, `pairs_*.jsonl`, `facts.json`: synthetic, generated by `kdlib/tasks.py` (seeds fixed in `hack/make_tasks.py`); no real people or data.
- `ref_base.pt`, `ref_sft.pt`: models trained by this course's own code on the data above (`hack/make_base.py`, `hack/make_sft.py`).
