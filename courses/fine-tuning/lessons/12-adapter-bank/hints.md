`__init__`: call `add_lora(model, targets, r, alpha, seed)`, then `self._live = dict(lora_parameters(model))` (name to live Parameter), `self._store = {}` (name to {layer name: tensor}), `self._active = None`. A helper `_sync()` writes the live tensors back: `if self._active is not None: self._store[self._active] = {n: p.detach().clone() for n, p in self._live.items()}`.
---
`add`: a generator `torch.Generator().manual_seed(seed + len(self._store))`; for each live name make `torch.empty_like(p)` and `torch.nn.init.kaiming_uniform_(t, a=5 ** 0.5, generator=g)` for `lora_A`, `torch.zeros_like(p)` for `lora_B`; store the dict. `activate`: validate the name, `_sync()`, then under `torch.no_grad()` either zero the B parameters (`None`) or `p.copy_(self._store[name][n])` for every live parameter; set `_active`.
---
`memory_report`: base values are the parameters whose name does not end with `lora_A` / `lora_B` (this includes the wrapped `base` layers inside the adapters); every adapter has the same number of values (`sum(p.numel() for p in self._live.values())`), times 4 bytes. If the isolation test fails, you probably return the stored tensors themselves from `state()` or forget `_sync()` before loading the next adapter.
