`lr_at` has two branches before the cosine: `if step < warmup: return lr * (step + 1) / warmup`, and `if step >= steps: return lr_min`. The cosine part is `lr_min + 0.5 * (1 + math.cos(math.pi * progress)) * (lr - lr_min)` with `progress = (step - warmup) / max(1, steps - warmup)`. Check by hand: warmup 0, steps 100: step 0 gives lr, step 50 gives the midpoint of lr and lr_min.
---
`get_batch`: `ix = torch.randint(0, len(ids) - block_size, (batch_size,), generator=generator).tolist()`, then `torch.stack([ids[i:i + block_size] for i in ix])` for x and the same slices shifted by one for y. Pass the generator, not a seed, so that a run consumes one random stream.
---
`finetune`: build `g = torch.Generator().manual_seed(seed)` once; `opt = torch.optim.AdamW([p for p in model.parameters() if p.requires_grad], lr=lr, betas=(0.9, 0.95), weight_decay=weight_decay)`. In the loop: set `pg["lr"]` for every `opt.param_groups`, get a batch, `_, loss = model(x, y)`, `opt.zero_grad(set_to_none=True)`, `loss.backward()`, `opt.step()`, append `float(loss.item())`. `model.train()` before the loop and `model.train(was)` after it. A model whose gradients are never cleared trains badly: zero them every step.
